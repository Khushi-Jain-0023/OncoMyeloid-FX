# Changelog

## 0.1.0 — 2026-11-16

- First local research release, including the five-phase evidence audit and descriptive analysis.
- Patient-level transcriptomic baseline: 11 patients, 6,124 genes, no primary association passing 5% FDR.
- Curated mouse marker screens, conservative orthology, separate MHCII/CD40/PD-L1 rankings and explicit missing evidence.
- Patient resampling, ablations, failure cases and an inconclusive independent-validation decision.
- Installable CLI, pinned environments, executed notebooks, final report, integrity manifest and clean-copy reproduction workflow.
- Optional web interface and GitHub/package-registry publication are not included in this release.

This version is a descriptive research artifact, not a validated predictive model.
