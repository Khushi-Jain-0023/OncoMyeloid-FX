# Phase 1 novelty assessment

2026-11-15. No demonstrated methodological novelty. Targeted review, not an exhaustive priority claim.

| Method | Established capability | Implication |
|---|---|---|
| [NicheNet](https://doi.org/10.1038/s41592-019-0667-5) | Ligand-target inference using expression and regulatory/signaling priors; ligand-treatment validation | Functional validation is not unique to this project. Ligand transcriptional response differs from arbitrary macrophage gene-to-T-cell function. Audit prior sources. |
| [LIANA+](https://doi.org/10.1038/s41556-024-01469-w) | Communication methods, consensus and sample-level/multimodal integration | Integration and communication ranking already exist. Match candidate universes and biological units. |
| [CellChat](https://doi.org/10.1038/s41467-021-21246-9) | Ligand/receptor/cofactor-based communication networks | Suitable only for compatible signaling candidates; scores are not measured T-cell suppression. |
| [scDrugPrio](https://doi.org/10.1186/s13073-024-01314-7) | Expression, cellular networks and pharmacology prioritize drugs | Strong integration overlap; drug ranks differ from gene knockout ranks. |
| [CellOracle](https://doi.org/10.1038/s41586-022-05688-9) | Regulatory networks and simulated TF perturbation with experimental validation | Perturbation prediction is established; cell-state change is a different endpoint. |
| [Macrophage suppression screen](https://pubmed.ncbi.nlm.nih.gov/39181134/) | Functional co-culture drug screening and combination validation | Functional prioritization exists experimentally; drugs are not direct gene labels. |

Potential contribution is a focused empirical test of independent perturbation evidence improving transcriptomic candidate prioritization. It requires the benchmark currently missing. Packaging integration or adding an interface is not itself novelty.
